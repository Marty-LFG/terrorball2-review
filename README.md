# TerrorBall 2 — web review build

A WebGL build of TerrorBall 2, published for team review. This repository holds the
**compiled build only**; the game source lives elsewhere.

- Single input: tap, click, or press Space to bounce the ball.
- Collect coins to open the exit. Green spikes are lethal.
- Works on desktop and mobile browsers, portrait or landscape.

Rebuilt and redeployed from the project's build tooling; edits here will be overwritten.
